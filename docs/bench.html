数据来源

Matbench Discovery（MBD）全部条目

指标说明 F1 / DAF：从 WBM 测试集中“发现”热力学稳定晶体的分类分数与相对随机挑选的富集倍数（越高越好）；MAE：形成能（距凸包能）误差，eV/atom； κSRME：103 个晶体晶格热导率的对称相对平均误差（0 最好、2 最差）；RMSD：弛豫结构与 DFT 结构的均方根偏差，Å； 对称匹配：弛豫后空间群与 DFT 一致的比例（symprec = 10−5）；RDF 误差：MD 径向分布函数与 DFT-MD 的差异； 力（targets）：EFS_G = 能量求导得力 / 应力（保守），EFS_D = 直接预测，_GM = 另含磁矩，EFSH = 训练时加入 Hessian，E = 只预测能量（不是力场）。更多术语见 术语表。

MD 用时：MBD 的 MD 任务（17 个体系）总用时与硬件；不同硬件之间不可直接比较。“—”表示该条目未提交此项。

MLIP Arena

稳定性（升温 / 加压）

升温：NVT，10 ps 内 300 → 3000 K；加压：NPT，10 ps 内 300 → 3000 K 且 0 → 500 GPa。“完整跑完”= 达到目标时长的 98% 以上；“平均完成度”= 崩溃前跑完的比例的平均值；n 为 步/秒 ∝ N−n 的拟合指数。

氢气燃烧（反应性 + 计时）

H256O128（384 原子），NVT 300 → 3000 → 300 K。水产率 = 最后一帧识别出的水分子数 / 128；未跑完的模型产率不可比。

状态方程（EOS）

对一组晶体做体积压缩 / 拉伸的能量曲线，统计非物理的能量差翻转次数、曲折度（理想 = 1）、压缩时能量与导数的 Spearman 单调性（理想为 ±1），以及缺失（失败）体系数。

契约、评分与证据边界

检查的是算法契约，不是“能 pip install”

按顺序传递结构、几何表示、特征、原子能 / 电荷、修正能、总能量、力与性质。检查缺失输入、表示不匹配、边界条件、完整能量的导数路径、直接力与保守目标冲突、色散重复计数以及周期偶极限制。

自定义模块还必须声明必需的阶段接口。通过仅说明这些声明没有发现规则内的冲突；未证明算法正确，也未检查框架、数值精度、权重维度、单位换算、许可证或部署接口。需要真正的适配、训练与验证才能成为 MLIP package。

准确度不能从模块名称推算

所有组合的能量 / 力 MAE、稳定性和应用域准确度都标为未评测。表达力只是基于结构的编辑量表，数据覆盖、参考泛函、训练预算、损失和分布外误差没有被模拟。模板分数也不是原模型的基准分数。

实际验证应包含独立测试集上的 E/F/应力误差、旋转与置换测试、能量–力有限差分、截断连续性、MD 能量漂移及同硬件吞吐。已有模型的实测记录另见 基准数据，不会自动转移给混搭模型。

展开可复核的评分公式（编辑规则 v1，不做综合排名）

所有数值最终截到 [1,5] 并保留一位小数。每个模块的开销 / 表达力基数可在选项中查看；自定义模块若没有相关自评，就显示“待定”。

  • 开销档位（低分更省） = 模块开销基数之和 + 0.25 log₂(N/1000) + 0.25 log₂(M/32) + 0.5 log₂(C/64) + 0.5 log₂(T_eff/2) + a + b。严格局域主干 T_eff=1，否则为 T。
  • 表达力 / 精度潜力 = 主干基数 + 0.15 log₂(T_eff/2) + 0.15 log₂(C/64) + a + b。适用球谐 / SO(2) 主干时 a=0.1(l−2)，否则为 0；MACE 主干 b=0.15(ν−3)，否则为 0。这是容量提示，不是普适准确度排序。
  • 物理约束 = 1 + 保守力 + 对称性 + 截断光滑性 + 广延性。完全满足每项加 1，已知近似 / 部分满足加 0.5，不满足加 0；未知声明不补成满分。
  • 显式长程 / 色散 = 1 + 静电项×2 + PolarMACE 场更新 + 显式色散。只统计显式模块，不把电荷输入、多跳消息或含色散训练标签算成显式求解器。
  • 空间并行友好度 = 5 − 消息通信罚项 min(2,T/4) − 全局运算罚项 1.5 − 全对枚举罚项 1；仅在对应项存在时扣分。输出覆盖 = 1 + 应力×0.5 + 额外输出契约数×0.75。

开销档位中的权重是公开的编辑启发式，不是 Big-O 的数值拟合。不要跨不同数据、硬件或精度把它解释为加速倍数。图构造、MPS 键维、张量积路径、极化更新数、倒空间分辨率、完整 Hessian 成本均需额外核算。

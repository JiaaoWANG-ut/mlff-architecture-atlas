一句话理解：MLFF 在学什么？

量子化学（DFT）可以精确算出一个原子构型的能量和受力，但很贵——几百个原子算一步要几分钟到几小时。 机器学习力场用神经网络去拟合这张“能量地形图”：

训练好之后，算一次能量和力只需毫秒级，于是可以跑百万步的分子动力学、筛选几十万种材料。

几乎所有 MLFF 都建立在同一个“局域分解”假设上：总能量 = 每个原子贡献之和，每个原子只受附近原子影响。

它带来线性标度（体系翻倍、计算量翻倍）和可迁移性；代价是截断半径 rc 之外的物理（长程静电、色散尾巴）被丢掉——这正是后面“弱相互作用”分析的核心。

四条“物理铁律”贯穿所有架构设计： ① 平移、旋转不变（整体移动/转动体系，能量不变）；② 同种原子交换不变（置换不变）；③ 原子进出截断球时能量要光滑（否则力会跳变、MD 会崩）；④ 力应当是能量的负梯度（保守场，能量守恒）。 不同家族的区别，本质上是用什么数学工具满足这些铁律、又付出多少计算代价。

通用流水线：从构型到能量、力与更多性质

下面 11 步是几乎所有 MLFF 共享的骨架。每一步点击“看各模型怎么做”，即可横向对比所有模型在这一步的具体实现（含公式与源码）。

1

输入构型：坐标、元素、晶胞（+ 电荷 / 自旋）

一个“构型”就是 N 个原子的位置 ri 和元素 Zi；晶体还要晶胞矩阵 L（三个晶格矢量）与周期边界条件；部分分子模型还需要总电荷 Q 和自旋多重度 S。 模型从不直接使用绝对坐标：整体平移或旋转后能量不应改变，所以后面每一步都只用相对几何（原子间矢量）。

给模型一张“原子点名册 + 房间尺寸”：谁（元素）、在哪（坐标）、房间多大，以及四面墙外是不是一模一样的房间（周期性）。

2

建图：截断半径内找邻居

只把距离小于截断半径 rc（通常 4.5–6 Å）的原子对连成“边”。周期体系要考虑晶胞镜像：原子可以和隔壁晶胞里的原子（甚至自己的镜像）相连。 每个原子的邻居数 M 一般 20–100，计算量 ∝ N·M —— 这就是 MLFF 线性标度的来源。有的模型还会构造“线图”（边与边相连，用来表示键角），或给每个原子设邻居上限（如 Orb、EquiformerV2 的 20 近邻）。

每个原子只“加好友”方圆 rc 内的原子；截断以外的原子，它一概不认识——长程静电和色散尾巴就在这一步被丢掉了。

3

几何编码：距离 → 径向基，方向 → 球谐 / 张量 / 键角

边向量 rij 拆成“距离 + 方向”。距离用一组光滑函数（高斯、Bessel、Chebyshev）展开成几十维向量，再乘一个在 rc 处平滑降到 0 的包络函数，保证原子进出截断球时能量和力连续。 方向的编码最能体现家族差异：描述符模型用键角 cos θ；不变 MPNN 用键角/二面角；笛卡尔等变模型直接用单位矢量与张量积 r̂⊗r̂；球谐等变模型用球谐函数 Ylm(r̂)。

把“邻居在哪”翻译成模型能读的语言：距离像收音机的不同频道（径向基），方向像把地球仪上的位置展开成一组“纬度带 + 经度波纹”（球谐）。

4

原子嵌入：元素（与电荷、自旋、任务）→ 初始特征

元素 Z 查表变成一个可学习向量 hi(0)，相当于“元素性格”的词向量。新一代通用模型还在这里加入总电荷、自旋、数据集/泛函标签（多保真、多任务），让同一个网络能区分 PBE 与 r²SCAN、阴离子与阳离子。

5

相互作用 / 消息传递：多体信息在这里产生

这是模型的“大脑”。每一层里，原子 i 从每个邻居 j 收到一条消息（邻居特征 × 几何决定的权重），把所有消息求和（保证置换不变）后更新自己的特征。重复 T 层后，原子 i 的特征就编码了约 T·rc 范围内的环境（感受野）。

等变模型的消息是一个张量积：把邻居的方向信息（球谐）和邻居特征按角动量规则（Clebsch–Gordan 系数）耦合，输出仍然随旋转正确变换：

体序（body order）衡量一次能同时“看到”几个原子的关联：两体（只看距离）→ 三体（键角）→ 四体（二面角）…… ACE / MACE 用“先求和、再相乘”的技巧在一层内得到高体序；描述符/线性模型（BPNN、ACE、NEP、DeePMD）没有多轮传话，而是一次性构造好多体描述符。

像“传话游戏”：每轮每个原子把听到的周围情况整理后再讲给邻居；传 T 轮后，你能间接知道 T 层“朋友圈”以外的事——但消息会被层层压缩，越远越模糊。

6

读出：特征 → 原子能

每个原子最终特征中旋转不变的标量部分（l = 0）经过一个小 MLP 变成一个数 Ei。原子能不是可观测量，只是把总能量“分摊”给原子的方式，但它保证能量随体系大小可加（广延性），模型才能外推到比训练集更大的体系。

7

能量汇总：求和 + 元素参考能 + 缩放平移

总能量 = 所有原子能之和，再加每种元素的参考能（孤立原子能 E0 或对训练集做线性回归得到），并用训练数据的统计量缩放/平移，让网络只需学习“偏离参考”的那一小部分。

8

长程项：把截断之外的物理补回来

前面所有信息都局限在感受野内。静电（∝ 1/r）和色散（∝ −C6/r6）衰减慢，截断会把它们丢掉。补救办法有三类： (a) 网络预测原子电荷 qi，再做库仑 / Ewald 求和；(b) 加上解析的 DFT-D3/D4 色散校正；(c) 隐式电荷 + Ewald（LES）、倒空间消息传递（Ewald MP）等“学出来的长程项”。

局域模型像近视眼，只看得清身边；长程项相当于给它配一副“看远处的眼镜”。

9

力：能量的负梯度（或直接预测）

主流做法：力 = 能量对坐标的负梯度，用自动微分（反向传播）一次算出所有原子的力。这样的力是保守的：沿闭合路径做功为零、MD 中能量守恒、声子和弹性常数等二阶性质自洽；代价是多一次反向传播（约 1–3 倍前向的时间和更多显存）。 另一类模型（Orb v2、EquiformerV2 OC/OMat 版等）用输出头直接预测力向量，更快，但这个力不再是任何能量的梯度。

能量是一张地形图，力就是“哪边下坡最陡”。保守力保证你绕一圈回到原点，上坡下坡正好抵消；直接预测的力则像一张手绘的“坡度示意图”，局部看着对，绕一圈可能多出（或少了）能量。
看各模型怎么做 →
10

应力 / 维里：对应变求导

给晶胞施加一个微小的对称应变 ε（原子坐标与晶格矢量一起变形），能量对 ε 的导数除以体积就是应力；同样由自动微分得到。应力是晶胞弛豫、NPT 分子动力学、弹性常数和状态方程的基础。

11

更多性质：再求导，或加读出头

有了可微的能量，很多性质都能“求导出来”：Hessian（二阶导）→ 声子谱、热导率、振动频率；对外电场求导 → 极化、Born 有效电荷；对磁矩求导 → 磁力。另一些性质靠额外的读出头直接预测：原子电荷、磁矩、偶极、不确定度（集成 / 方差头）。

四个关键概念

不变 vs 等变

不变：旋转体系后输出不变（能量）。等变：旋转后输出“跟着一起转”（力、偶极）。 不变模型的中间特征全是标量（距离、角度），信息损失但便宜；等变模型的中间特征带方向（矢量、张量、球谐系数），能更完整地保留几何信息，数据效率高、精度高，但运算更贵。

体序（Body order）

一个特征最多同时依赖几个原子的相对位置。两体只能区分距离（无法区分键角），三体能区分键角，四体能区分二面角 / 手性。 经典势（LJ、EAM）基本是两体或嵌入两体；ACE / MACE 每层可达 4–5 体；消息传递靠堆层“间接”提高体序。

感受野（Receptive field）

原子能能“看到”的最远距离。严格局域模型（ACE、NEP、DeePMD、Allegro）= rc；T 层消息传递 ≈ T·rc。 感受野越大，越能捕捉中程效应，但多 GPU 并行时需要交换的“幽灵原子”也越多；而且它仍是有限的，无法表达 1/r 的静电尾巴。

保守力 vs 直接力

保守力（F = −∇E）满足能量守恒、二阶导数自洽，适合 NVE MD、声子、热导；直接力省掉反传、更快，但会造成能量漂移，在声子/热导这类依赖二阶导的任务上明显变差（见 深度分析 中 κSRME 数据）。

发展时间线

核心结论速览

① 架构主线：从“手工描述符”到“等变大模型”，再到“去约束”

2007–2018 年以描述符 + 小网络、线性多体展开为主（BPNN、GAP、SNAP、MTP、ACE、DeePMD）；2017 年后不变消息传递（SchNet、DimeNet、M3GNet、CHGNet）兴起；2021 年后等变网络（NequIP、MACE、Allegro、Equiformer、eSEN、UMA）成为精度主力；Orb、PET 则选择放弃结构性等变，用数据增强换速度。

② 速度由“构件 + 层数 + 力的求法 + 实现”共同决定

同平台 384 原子反应 MD（MLIP Arena）中，直接力的 Orb 约 55 步/秒，保守力的 MACE、MatterSim 约 32–34 步/秒，SevenNet 约 24，EquiformerV2 约 9，eSCN 约 4.6，CHGNet 约 3，M3GNet 约 1.6。详见速度分析 →

③ 弱相互作用是通用大模型的普遍短板

主流材料基础模型都训练在 PBE(+U) 数据上——数据里本来就没有色散；绝大多数也没有任何显式静电。补救要靠外挂 D3/D4 或 LES 一类长程模块；真正把电荷 + 静电 + 色散都内置的是 PhysNet、SpookyNet、AIMNet2、SO3LR、BAMBOO、FeNNix 等“分子 / 电解质”路线。详见弱相互作用分析 →

④ 保守力决定了二阶性质能不能用

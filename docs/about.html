数据与方法

这个网站怎么做出来的、数字从哪里来、哪些地方需要谨慎看待。

做法

① 源码快照

把 个上游仓库在固定 commit 浅克隆下来（见下方 源码快照）。模型页上的每一段代码都是从这些 commit 的文件中按行号截取的原文，并附带指向该 commit 的永久链接，可以逐行核对。

② 逐个阅读、统一建模

为 个架构 / 模块逐一阅读源码与官方配置，按同一模板整理：从“输入构型”到“其他性质”的 11 个流水线阶段（每步有通俗解释、公式与源码），统一的架构字段（等变性、lmax、体序、截断、层数、力的类型、长程、色散……），关键超参数、预训练权重与注意事项。

③ 自动校验

构建脚本检查每个条目：必填字段齐全、取值合法；每段代码引用的文件存在、行号范围有效、摘录不超过 45 行，并且必须包含指定的锚点字符串——如果行号错位，构建会直接失败。基准条目的键名也会与基准仓库核对。

④ 基准与图表

基准数字由脚本直接从 Matbench Discovery 的 models/*/*.yml 与 MLIP Arena 的结果文件中提取，不手工抄录（见 基准数据）。网站是纯静态页面，所有图表都在浏览器中由这些数据实时绘制。

能力归类规则

分析页与对比页的长程 / 色散 / 感受野图表使用一份从各模型架构字段提炼出来的归类表（data/curated.json）。规则如下：

字段含义取值
rc代表性 / 基础模型发布配置的截断半径（Å）数值；配置不同时以 cfg 指明的那个为准
T扩大感受野的消息传递层数0 = 严格局域（描述符、线性模型、Allegro 等）
rf名义感受野（Å）T = 0 时等于 rc，否则 ≈ T × rc；空 = 全局或不适用
lr长程静电无；可选扩展 = 官方代码提供开关或变体，但默认 / 基础模型不启用；内置 = 默认架构的一部分；本身即长程模块
disp色散（vdW）无；外挂 D3/D4 = 官方示例或计算器支持叠加经验色散；可选内置项；内置；本身即色散模块
qs总电荷 / 自旋输入无 / 可选 / 内置
props官方提供接口的额外输出Hessian、原子电荷、偶极、极化率、Born 有效电荷、磁矩 / 自旋、不确定度

“训练数据是否含色散”是另一回事：一个架构即使没有任何色散项，用含 D3 / VV10 的数据训练后也能在截断内学到色散（见分析页 B2、B5）。

评分（1–5）

每个完整势在 6 个维度上相对于整个领域打分，每个分数都附一句理由（见各模型页“评分”一节）。这是编辑判断，用来快速对比，不是测量值：

维度看什么锚点
速度每原子推理吞吐5 = 描述符 / 线性模型（NEP、SNAP、ACE、压缩后的 DeePMD）；3 = MACE 级；1 = 大型等变 Transformer（EquiformerV2、eSEN-30M、UMA-L）
表达力体序 + 角分辨率 + 容量5 = 高体序等变（MACE、完备 ACE）；1 = 只有两体 / 径向
长程 / 弱相互作用截断之外的物理1 = 严格局域无扩展；2 = 只有消息传递感受野；3 = 可选 D3 / 简单电荷；4 = 内置静电或色散；5 = 电荷平衡 + 静电 + 色散（+ 总电荷 / 自旋）
并行可扩展性大体系、空间分解、多 GPU MD5 = 严格局域且有 LAMMPS 并行（Allegro、NEP、DeePMD）；1 = 只能整图计算
物理约束保守力、截断处光滑、广延性、短程排斥 / ZBL、对称性精确5 = 全部满足
性质覆盖E / F / S 之外的官方输出1 = 只有能量和力

已知局限

Architecture Foundry 使用独立的人工模块目录与契约规则，检查表示、边界、能量汇总、求导路径和物理项冲突。其开销与表达力分数是公开公式的设计启发式，不沿用原模型的实测性能；所有混搭的准确度均为未评测。自定义模块只验证声明，不验证实现。完整规则与来源见 架构工坊的方法说明。DPA-4.1 暂以有来源的 DPA-4 / SeZM 作为参考骨架，独立版本尚待核对。
  • 一个架构，多种配置：截断、层数、lmax 等随发布权重而变；本站取“代表性 / 基础模型”配置，并在模型页写明来源。部分基准条目与源码默认配置不一致，例如 CHGNet 0.3.0 源码的建图半径为 6 Å而 MBD 记 5 Å、Orb v2 源码为 6 Å而 MBD 记 10 Å、AlphaNet 的层数与截断（MBD 的 MPtrj 条目记 6 层 / 6 Å，配置默认更小），均已在对应模型页标注。
  • 代码版本：fairchem v2 主分支已不再包含原始 eSCN / EquiformerV2 / 早期 eSEN 的实现；相关页面引用的是当前 fairchem 中保留的代码与 equiformer_v2 原仓库。MBD 中的 eSEN-30M 权重来自 fairchem v1，与当前代码可能有差异。
  • 源码内部不一致：如 schnetpack README 称默认表示为 SchNet，而配置文件实际默认 PaiNN；FitSNAP（SNAP 页）的 LICENSE 为 GPL-2.0 而 pyproject 分类器写 MIT；NewtonNet 的 license.txt 为学术非商用而 pyproject 写 MIT。本站以实际代码 / LICENSE 文件为准，并在模型页写明。
  • 文献信息：少数条目（如 aenet、ANI、GAP、eSCN、NewtonNet）的完整论文标题或作者在仓库中找不到出处，按文献整理；EqNorm、MACE-SOYO、Ewald MP 暂无正式论文链接。少量公式（如 GAP 所依赖的 libAtoms 中的截断函数）不在克隆的仓库里，按文献给出并在页面注明。
  • 基准的边界：MBD 与 Arena 只覆盖部分模型，且以 PBE 为参考；它们几乎不测弱相互作用、带电体系与分子体系。速度数字只在相同硬件内比较。
  • 评分与归类是编辑判断；如发现错误，欢迎在 GitHub 提 issue。

复现

仓库根目录下运行（需要 git 与 Python 3；提取基准数据还需要 numpy 与 PyYAML）：

bash tools/fetch_sources.sh          # 按 data/MANIFEST.tsv 中的固定 commit 克隆 sources/
python3 tools/extract_benchmarks.py  # 从 MBD / Arena 原始文件生成 docs/data/benchmarks.js
python3 tools/build_data.py          # 校验 data/models/*.json，截取源码，生成 docs/data/*.js
python3 -m http.server -d docs 8000  # 本地预览 http://localhost:8000

给 fetch_sources.sh 加 --latest 则改为拉取各仓库最新版本；源码行号如有偏移，build_data.py 会逐条报出失效的引用。
